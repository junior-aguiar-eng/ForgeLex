## Decisões e limites

- O modo diário pula `resource_id` já concluído; não detecta alteração
  retroativa de bytes no mesmo ID. Uma reconciliação completa controlada deve
  comparar hashes periodicamente.
- `lagHours` mede a última execução concluída, não a data de publicação do
  último recurso pelo STJ. As duas datas são exibidas separadamente.
- O banco da homologação ainda usa o segredo de banco já existente; não foi
  criado um principal PostgreSQL exclusivo para ingestão. A identidade Google
  Cloud do job é dedicada e tem acesso restrito ao segredo.
- O código e este registro ainda não foram commitados: o usuário determinou
  commit e push automáticos apenas a cada três fases concluídas.
