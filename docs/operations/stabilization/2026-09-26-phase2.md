ainda continha o slogan rejeitado e `apps/web/index.html` não tinha a headline
integral. Após as correções, passou nos três alvos: README, HTML e componente
público. O gate final desta fase inclui Prettier, `git diff --check`, resolução
dos links locais dos documentos canônicos e a verificação de hash da cópia.
O CI remoto só poderá validar o commit final quando houver PR ou integração na
branch monitorada pelo workflow; o push da branch isolado não prova CI verde.

versionado é ignorado pelo formatador para preservar o hash de origem. A
verificação de links encontrou 28 referências locais resolvidas e nenhuma
quebrada. `pnpm test:e2e:public` passou 6/6 após a alteração no HTML.
